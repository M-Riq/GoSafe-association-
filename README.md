# GoSafe-association-

ONG informatif website — site bilingue (FR / EN) de l'association GOSAFE, construit avec Next.js 16.

## Développement

```bash
npm install
npm run dev
```

## Production (Hostinger, Netlify, ou tout hébergeur Node.js)

- Node.js : 20.9 ou plus récent (22 recommandé)
- Build : `npm run build`
- Démarrage : `npm start`

Le site nécessite un serveur Node.js (redirection de langue via `proxy.ts`, optimisation des images) : ce n'est pas un export statique.
